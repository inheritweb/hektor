## Before you begin

You need an active Hektor account and an active organisation administrator membership. If your membership is suspended, ask another organisation administrator or a platform administrator to restore it.

## Sign in and select an organisation

1. Open Hektor and sign in with an email code or Google.
2. Open the account switcher at the bottom of the application menu.
3. Select the organisation you want to administer.
4. Check that **Users**, **Cohorts** and **Groups** appear in the menu.

Hektor remembers the selected workspace in this browser. Every organisation request is checked against both your signed-in account and current active membership; knowing or changing an organisation identifier does not grant access.

## Switch organisation

1. Open the account switcher.
2. Select another organisation for which you have an active membership.
3. Confirm that the dashboard totals and navigation now describe that organisation.

The same login session is used across workspaces. To leave organisation administration, select **Personal account**.

Platform administrators can enter an organisation workspace without creating an organisation membership. Hektor records that as platform access rather than impersonating an organisation administrator.

## If an organisation is missing

- Confirm that you selected the correct Hektor account.
- Ask an administrator to check that your membership is linked, active and has the **Organisation admin** role.
- Refresh after a newly accepted invitation or restored membership.
