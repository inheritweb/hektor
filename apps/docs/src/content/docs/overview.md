description: What Hektor is and how these docs are organised.
---

Hektor is a learning platform used by organisations and individuals. These docs
are organised around the people who use Hektor day to day:

- **Org Admins** — manage an organisation's members, roles, and identity setup.
- **Tutors** — deliver and manage learning content for their organisation.
- **Org Learners** — learn as a member of an organisation.
- **Individual Learners** — learn in a personal account, outside any organisation.

Each section will grow independently as features ship. This overview page will
expand to cover shared concepts (accounts, entitlements, identity) that apply
across all personas.
